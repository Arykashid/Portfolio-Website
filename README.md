# Ary Kashid — AI & Data Science Engineer Portfolio

A production-ready, fully mobile-responsive personal portfolio website for **Ary Kashid** (AI & Data Science Engineer), built with Next.js (App Router), TypeScript, and Tailwind CSS.

## ⚡ Features

- **Obsidian Atelier Aesthetic**: Bespoke dark charcoal base (`#121315`), razor-sharp micro-typography, warm amber gold accents (`#f7bd55`), and electric cyan telemetry indicators (`#00daf3`).
- **Typography**: Display headlines set in `Newsreader` serif, interface and body typography in `Geist`, and blueprint system markers in `JetBrains Mono`.
- **100% Mobile Responsive**: Mobile-first architecture with strict zero horizontal overflow, prioritized photo stacking, 44px+ touch targets, and mobile drawer navigation.
- **Skills Infinite Marquee**: 3 independent auto-scrolling infinite marquees (ML & Data, ML Methods, Engineering) with seamless continuous loop, hover-pause, and edge gradient masks.
- **Selected Works & Case Studies**:
  - **CrashGuard AI**: Autonomous CPU workload forecasting and infrastructure resiliency engine with real-time telemetry charts, LSTM + XGBoost ensemble breakdown, and metrics.
  - **RAG-Based AI Teaching Assistant**: Multimodal educational copilot with Whisper ASR audio extraction, timestamp synchronization, and reciprocal rank fusion retrieval.
- **Interactive Micro-Interactions**: One-click email copying with instant `COPIED!` feedback, interactive Resume viewer modal with print/save capabilities, and scroll-triggered reveals.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Vanilla CSS Tokens
- **Icons**: Lucide React & Google Material Symbols
- **Fonts**: Google Fonts (`Newsreader`, `Geist`, `JetBrains Mono`)
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Arykashid/Portfolio-Website.git

# Navigate to the project directory
cd Portfolio-Website

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Building for Production

```bash
# Compile and build optimized static output
npm run build

# Start production server
npm run start
```
